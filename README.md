# RakshNet Frontend Replica

An exact frontend replica of the [RakshNet Website](https://signellent.com/rakshnet/) by Signellent Technologies Limited.

## Features
- **Strictly Frontend-Only**: React.js, Vite, Tailwind CSS, Lucide React, and React Router.
- **Exact Design Match**: 1:1 reproduction of typography, color palette, responsive layout, animations, and inline SVG assets extracted directly from the reference website.
- **High-Performance Architecture**: Component-driven structure, lazy-loaded video hero, IntersectionObserver scroll reveal animations.
- **Direct Route Support**: Accessible at `/` and `/rakshnet/`.

## Getting Started

### Development
```bash
npm run dev
# or within rakshnet-frontend:
cd rakshnet-frontend
npm run dev
```

### Production Build
```bash
npm run build
```
